# 中焦周天光迹

人体权威连接仍由 Human 的 `HumanAnatomy` 定义：

```text
左肺 → 左大肠 → 右胃 → 右脾 → 右肺 → 右大肠 → 左胃 → 左脾 → 左肺
```

本包为全部人体连接提供路线，以下四条采用专属中间坐标，其余连接由本包从 Human 模型提取两端网格中心，UI 负责沿源/目标网格衔接：

| 实际连接 ID | 表现 |
|---|---|
| `left_large_intestine_meridian.to.right_stomach_meridian` | 左大肠经人中进入右胃 |
| `right_large_intestine_meridian.to.left_stomach_meridian` | 右大肠经人中进入左胃 |
| `left_spleen_meridian.to.left_lung_meridian` | 左中焦回流至左肺 |
| `right_spleen_meridian.to.right_lung_meridian` | 右中焦回流至右肺 |

`HumanMeridianRoutes` 直接使用 Human 模型局部坐标：人中为 `(0, 1.67, 0.25)`，左右沿 X=0 镜像。大肠交叉取意“交人中，左之右，右之左”；回流取意肺经“起于中焦”。这属于游戏表现，不改动权威连接的 0.3 米距离与运输时间。

提供者返回不可变 `Point` 列表；模板和实际连接必须匹配，四条专属路线另须匹配 from/to 端口。普通连接必须能找到端口与绑定模型，无法提供有效路线即抛错；UI 强制唯一装配并校验 2～256 个坐标，再衔接源/目标网格。只在两端已解锁且有真实游离态在途时绘制。旧身体按自身实际连接提供路线，同侧连接不会被客户端自动改成跨侧路线。

后续各条人体周天的路线在本包增加；“小周天”留给任督环，当前未实现。现有静态身体模型没有独立的模块间连线，本次只移动运输光迹的表现。

旧存档不迁移。安装本包不改写连接；身体结构、在途与资源账本始终由权威宿主决定。
