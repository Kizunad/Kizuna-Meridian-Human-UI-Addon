# 人体客户端表现

本仓库专门承载人体周天光迹、人中交叉与中焦回流坐标，以及以后只对人体有意义的内观或模型表现。当前为全部人体连接提供光迹，其中中焦周天四条连接采用专属坐标；尚无额外人体界面或新模型。

| 仓库 | 职责 |
|---|---|
| Framework | 身体、资源、通路和权威结算；不定义本包的光迹协议 |
| Human | 人体连接拓扑、数值、规则、已有模型及经脉 ID |
| UI | 通用窗口、模型画布、真实运输展示与客户端光迹扩展点 |
| Human-UI | 直接引用人体模型和 ID，通过 Java 接口提供人体路线 |

本包只有 `client/`，没有第二份身体账本或服务端模块。Meridian 各 Addon 按适用端整套安装，拆仓仅用于管理职责。UI 强制运行依赖本包，本包编译依赖 Human 与 UI 的公开接口；缺少接线或路线直接报错。已有 Human 模型继续复用，之后人体专属的 UI 代码与表现增量放在本仓。

客户端路线通过 `MeridianRouteProvider` 和 Fabric `meridian_ui_routes` 入口装配，不再新增 Framework Protobuf 路径字段。本地扩展不改变现有身体快照与跨端协议。

详见[构建与验证](Integration.md)、[路线规则](Routes.md)及[现有依赖排查清单](Dependency-Audit.md)。
